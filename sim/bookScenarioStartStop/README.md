# Simulations of Start and Stop Scenario

Reference scenario I for characterizing and comparing microscopic traffic models.

These "fact Sheets" are used and discussed in the text 
book [Traffic Flow Dynamics, Data, Models and Simulation](http://www.traffic-flow-dynamics.org),
see the [sample chapter](https://traffic-flow-dynamics.org/res/SampleChapter11.pdf) on continuous models.

Run and plot the simulations with `runall`.

## Continuous Car-Following Models

* Adaptive Cruise Control model: startStop_ACC.xprj
* Improved Full Velocity Difference Model: startStop_ImprovedFVDM.xprj
* Full Velocity Difference Model: startStop_FVDM.xprj
* Intelligent Driver Model with Memory: startStop_IDMM.xprj
* Intelligent Driver Model: startStop_IDM.xprj
* Intelligent Driver Model with Noise: startStop_IDM_w_noise.xprj
* Improved Intelligent Driver Model: startStop_IIDM.xprj
* Optimal Velocity Model: startStop_OVM.xprj

For visualization run with the viewer `startStop_all_continuous.xprj`

## Iterated Map Models

* startStop_GIPPS.xprj
* startStop_KRAUSS.xprj
* startStop_NEWELL.xprj

For visualization run with the viewer `startStop_all_iteratedmaps.xprj`

## Cellular Automata Models

* startStop_BARL.xprj
* startStop_KKW.xprj
* startStop_NSM.xprj

For visualization run with the viewer `startStop_all_ca.xprj`
