# Simulations of Highway with Onramp Scenario

Reference scenario II for characterizing and comparing microscopic traffic models.

These "fact Sheets" are used and discussed in the text 
book [Traffic Flow Dynamics, Data, Models and Simulation](http://www.traffic-flow-dynamics.org),
see the [sample chapter](https://traffic-flow-dynamics.org/res/SampleChapter11.pdf) on continuous models.

## Continuous Car-Following Models

* Adaptive Cruise Control model: onramp_ACC.xprj
* Full Velocity Difference Model: onramp_FVDM.xprj
* Intelligent Driver Model with Memory: onramp_IDMM.xprj
* Intelligent Driver Model: onramp_IDM.xprj
* Improved Intelligent Driver Model: onramp_IIDM.xprj
* Optimal Velocity Model: onramp_OVM.xprj

## Iterated Map Models

* onramp_GIPPS.xprj
* onramp_KRAUSS.xprj
* onramp_NEWELL.xprj

## Cellular Automata Models

* onramp_BARL.xprj
* onramp_KKW.xprj
* onramp_NSM.xprj
